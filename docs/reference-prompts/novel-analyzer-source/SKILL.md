# 长篇小说拆分与综合分析

## 核心流程

本技能分两大阶段处理长篇小说：先拆分，再逐段总结分析。

### 阶段一：拆分

1. 识别输入小说文件。原生支持 `.txt` 和 `.md`。`.docx`、`.pdf`、`.epub` 等格式需先提取纯文本，再继续处理。
2. 运行 `scripts/split_novel.py`。以源文件所在目录为工作区，除非用户指定其他输出位置。
3. 以文章标题为项目文件夹。拆分文件放在 `<输入父目录>\<文章名>\输出拆分`，总结放在 `<输入父目录>\<文章名>\输出总结`。
4. 按编号顺序阅读 `输出拆分` 中的文件。
5. 总结第 N 部分前，先阅读同文章 `输出总结` 中所有先前总结作为上下文。
6. 将当前总结写入 `输出总结`。
7. 为该部分生成一个高度压缩的内容标签，然后用该标签重命名拆分文件和总结文件。

### 拆分命令

```powershell
python "<skill-dir>\scripts\split_novel.py" "<小说路径.txt>"
```

默认参数：
- 输出目录：`<输入父目录>\<文章名>\输出拆分`
- 目标大小：200000 非空白 Unicode 字符
- 优选范围：150000-250000 字符
- 初始文件名：`《文章名》-拆分001-待总结.md`
- 清单文件：`输出拆分\manifest.json`

拆分器检测 Markdown 标题、中文章节标题（如 `第十章`、`第3节`、`第一卷`）以及常见开篇/结尾标题（如 `序章`、`楔子`、`尾声`、`后记`）。优先在章节边界拆分；若无章节结构，则回退到段落/行边界。

## 阶段二：逐段总结与七维分析

总结前必读 `references/output-format.md`。每份总结必须覆盖以下全部维度。

---

### 子技能一：角色分析（character-analysis）

**用途**：识别主角、配角、次要人物，提取角色卡片，归档到长篇小说档案。

**工作流**：
1. 识别角色层级：主角、配角、次要人物。出现次数少但印象深刻或揭示文章深层意图的次要人物也要收录。
2. 从行为、对话、选择、反应、其他角色视角中提取证据。
3. 有先前总结时进行对比，标记动机、信念、能力、关系、地位的变化。
4. 区分确认事实与推测，不确定特征标注"推测"。
5. 返回可合并到长篇档案的精简角色卡片。

**角色卡片字段**：
- **标签**：4-10 个字，概括角色的叙事功能或内在驱动力。
- **层级**：主角 / 配角 / 次要人物。
- **成长历程**：因本段内容发生的变化。
- **思想发展**：信念、价值观、恐惧、执念或世界观的转变。
- **能力变化**：新能力、失去的能力、暴露的限制、隐藏的潜力。
- **年龄/身材/样貌**：仅收录文本支持的事实，否则写"未明"。
- **标志性特征**：一个物品、声音、手势、短语、伤疤、气味、衣物或习惯，让角色一出现就能被辨认。
- **核心动机**：角色当前想要什么，以及可能驱动它的更深层需求。
- **主要冲突**：外部对手和内在矛盾。
- **说话习惯**：方言、口吻、句长、礼貌程度、口头禅、讽刺、克制或情绪泄露。

**输出格式**：

```markdown
## 角色分析

### 角色名

- 标签：
- 层级：
- 成长历程：
- 思想发展：
- 能力变化：
- 年龄/身材/样貌：
- 标志性特征：
- 核心动机：
- 主要冲突：
- 说话习惯：
- 证据/推测：
```

**质量标准**：不要机械罗列名字。解释每个角色对故事情感压力、主题、悬念、冲突或世界观的意义。

---

### 子技能二：冲突分析（conflict-analysis）

**用途**：分离故事的长期引擎与局部章节冲突。

**工作流**：
1. 识别核心冲突：能支撑整个故事的起始矛盾或压力。
2. 识别当前章节或拆分部分内的次要冲突。
3. 说明冲突如何体现：直接对抗、隐藏压力、社会规则、资源限制、身份问题、情感创伤或道德选择。
4. 跟踪升级：什么变了、谁获得杠杆、谁失去选项、出现什么新代价。
5. 标记状态：未解决、暂时压制、虚假解决、已转化或已解决。

**冲突类型**：
- **核心冲突**：故事的持久动力，即使不直接点明也应持续回响。
- **次要冲突**：章节、场景、关系、动作序列或支线中的局部张力。
- **内在冲突**：角色不可兼容的欲望、信念、内疚、恐惧或忠诚。
- **外在冲突**：人对人、人对机构、人对世界规则、人对生存条件。

**输出格式**：

```markdown
## 冲突分析

### 核心冲突

- 冲突表述：
- 起因：
- 持续体现：
- 当前升级：
- 暂未解决的问题：

### 次要冲突

| 冲突 | 参与方 | 起因 | 升级方式 | 当前状态 |
|---|---|---|---|---|
```

**质量标准**：不要将冲突简化为"善与恶"，除非文本确实如此。要命名压力、赌注和任何一方获胜的代价。

### 子技能三：核心悬念分析（core-suspense-analysis）

**用途**：维护长篇小说的悬念台账。

**工作流**：
1. 识别文本希望读者持续关注的谜团。
2. 分类悬念对象：物件、意象、能力、身份、记忆、规则、事件真相、关系秘密或更大阴谋。
3. 记录文本向真相推进的程度：暗示、线索、部分揭示、虚假答案、矛盾、接近答案、完全揭示或更大悬念。
4. 跟踪谁知道什么：读者、主角、反派、叙述者、配角。
5. 保持延迟揭示纪律。无文本支持不要提前"破解"谜团。

**悬念台账字段**：
- **悬念标签**：简短名称。
- **悬念对象**：承载谜团的事物。
- **已知信息**：已揭示的事实。
- **新增线索**：本段新增的内容。
- **误导/遮掩**：可能是虚假或不完整的部分。
- **信息差**：谁知道、谁不知道。
- **揭示阶段**：伏笔 / 逼近 / 部分揭示 / 反转 / 完全揭示 / 引出更大悬念。
- **后续追踪**：后续部分需检查的内容。

**输出格式**：

```markdown
## 核心悬念分析

| 悬念 | 对象 | 已知信息 | 新增线索 | 信息差 | 揭示阶段 | 后续追踪 |
|---|---|---|---|---|---|---|
```

**质量标准**：好的悬念笔记让问题保持活力。应帮助后续总结识别反复出现的意象、被隐瞒的名字、可疑的能力和延迟的解释。

---

### 子技能四：背景/世界观分析（worldbuilding-analysis）

**用途**：将背景细节转化为可复用的世界档案。

**工作流**：
1. 提取世界规则和限制，而非仅仅是布景。
2. 将时代信息记录为时间线素材：历史、政治格局、技术水平、修炼阶段、灾难、战争、朝代、机构或记忆碎片。
3. 按功能和时间区分地点：主要活动地、分支活动地、起源地、隐藏地、禁地、目的地。
4. 对玄幻、科幻、悬疑等类型设定，说明关键规则、代价、限制和例外。
5. 跟踪背景如何施压角色选择和冲突。

**档案字段**：
- **世界观**：核心规则与社会结构。
- **时代背景**：历史阶段与时间线记忆。
- **地点**：当前主要地点、分支地点、过去地点、隐藏空间。
- **势力/制度**：组织、家族、政府、门派、公司、阶级。
- **关键设定**：能力、科技、魔法、修炼、法律、禁忌、经济、通讯、交通。
- **限制与代价**：什么不能自由做以及代价是什么。
- **剧情作用**：设定如何制造冲突、悬念或角色压力。

**输出格式**：

```markdown
## 背景/世界观分析

### 世界观

### 时代背景/时间线记忆

### 地点

| 地点 | 类型 | 时间阶段 | 相关人物 | 剧情作用 |
|---|---|---|---|---|

### 关键设定

### 限制与代价
```

**质量标准**：优先记录具体设定规则而非氛围描写。如果设定能改变角色可以做的事，就记住它。

---

### 子技能五：故事大纲分析（story-outline-analysis）

**用途**：将小说段落转化为因果时间线。

**工作流**：
1. 按故事时间而非阅读顺序列出事件，除非文本依赖非线性叙事。
2. 当同时行动重要时，分别跟踪不同角色。
3. 为每个事件识别起因、行动、结果和影响。
4. 标记高潮。长篇小说可有多个高潮：场景高潮、弧线高潮、情感高潮、揭示高潮、战斗高潮或战略高潮。
5. 保留未解决的线索供后续总结使用。

**事件字段**：
- **时间/顺序**：已知则用绝对时间，否则用相对顺序。
- **人物/势力**：谁行动或受影响。
- **事件**：发生了什么。
- **起因**：为什么发生。
- **影响**：之后什么改变了。
- **高潮/转折**：是否为高峰、反转、揭示或决策点。
- **后续线索**：后续部分应跟踪的内容。

**输出格式**：

```markdown
## 故事大纲分析

### 时间线

| 顺序 | 人物/势力 | 事件 | 起因 | 影响 | 高潮/转折 |
|---|---|---|---|---|---|

### 分线梳理

### 高潮位置

### 后续影响
```

**质量标准**：不要只总结"发生了什么"。要保留为什么发生以及它改变了什么。

---

### 子技能六：叙事视角分析（narrative-perspective-analysis）

**用途**：识别谁在看、谁知道、读者被允许知道多少。

**工作流**：
1. 确定叙事人称：第一人称、第三人称有限、第三人称全知或混合。
2. 识别视角持有者：主角、配角、叙述者、多角色或外部镜头。
3. 跟踪读者、叙述者、主角和其他角色之间的信息差。
4. 评估沉浸感和悬念效果。第一人称增强即时感；有限第三人称控制发现；全知第三人称可扩大规模和反讽。
5. 注意视角切换及其作用：澄清、误导、减速或提升张力。

**输出格式**：

```markdown
## 叙事视角分析

- 叙事人称：
- 视角范围：
- 当前视角人物：
- 信息差：
- 可靠性：
- 视角切换：
- 对悬念/节奏/人物理解的影响：
```

**质量标准**：聚焦叙事控制而非语法标签。说明所选视角让读者知道什么、感受什么或误解什么。

---

### 子技能七：节奏控制分析（pacing-control-analysis）

**用途**：理解场景如何加速、减速、收紧或释放张力。

**工作流**：
1. 识别主导模式：动作、内心独白、场景描述、对话、过渡或叙述。
2. 分析句子和段落节奏。短句短段落常制造紧迫感；长句可深化心理或减慢观察。
3. 检查动作场景的即时性、因果清晰度和压力。
4. 检查内心独白的心理深度，避免空洞重复。
5. 检查场景描述的有效感官细节，避免过度修饰。
6. 检查对话的角色身份、张力、潜台词和简洁性。

**输出格式**：

```markdown
## 节奏控制分析

- 主导节奏：
- 最快位置：
- 最慢位置：
- 动作处理：
- 内心独白：
- 场景描述：
- 对话场景：
- 紧张/缓和变化：
- 对阅读体验的影响：
```

**质量标准**：将节奏与故事功能挂钩。说明节奏是否支持悬念、冲突、角色情感、世界观或章节钩子。

## 总结模板

参考 `references/output-format.md`。每份总结必须包含：

```markdown
# 《文章名》-总结001-主要内容标签

- 标签：主要内容标签
- 对应拆分：`《文章名》-拆分001-主要内容标签.md`
- 处理范围：章节/段落范围；估算字数
- 前情上下文：说明本次总结参考了哪些先前总结；第一段写"无"

## 核心摘要

用 600-1200 字概括本部分主线，保持因果清晰：谁做了什么，为什么，造成什么后果，留下什么问题。

## 故事大纲

按时间线列出关键事件、转折、高潮和影响。若多条人物线并行，按人物或地点分组。

## 角色

记录主角、配角、印象深刻的次要人物。关注标签、成长历程、思想发展、能力变化、年龄/身材/样貌、标志性特征、核心动机、主要冲突和说话习惯。

## 冲突

区分贯穿全书的核心冲突和本部分的次要冲突。说明冲突如何被体现、升级、遮掩或暂时解决。

## 核心悬念

记录被隐藏、部分揭露或反转的信息。包括物件、意象、能力、身份、真相、误导和更大悬念。

## 背景/世界观

记录时代背景、地点、世界规则、势力结构、关键设定和时间线记忆。玄幻、科幻等类型要写清设定如何影响剧情。

## 叙事视角

说明叙事人称和视角范围：第一人称、第三人称有限、第三人称全知或混合视角。记录视角切换对悬念和信息差的影响。

## 节奏控制

分析动作、内心独白、场景描述、对话密度、段落长短和紧张/缓和节奏。指出本部分节奏最快和最慢的位置。

## 伏笔追踪

列出仍需后文验证的伏笔、未解问题和可疑细节。
```

## 标签与文件命名

总结完一个部分后，选择 4-12 个中文字符的内容标签。标签必须高度抽象、承载内容、适合长篇小说档案浏览。

标签要求：
- 抓住主要故事动向，而非泛泛主题。
- 避免空标签如 `剧情发展`、`人物成长`、`故事推进`。
- 避免文件名禁字符：`< > : " / \ | ? *`。
- 好标签示例：`边城疑云`、`宗门暗潮`、`身世裂变`、`旧怨复燃`、`帝都棋局`。

最终文件名：
- 拆分文件：`《文章名》-拆分001-主要内容标签.md`
- 总结文件：`《文章名》-总结001-主要内容标签.md`

---

## 完成检查

全部完成需满足：
- `<文章名>\输出拆分` 存在且包含编号 Markdown 拆分文件。
- `<文章名>\输出总结` 存在且包含匹配的编号 Markdown 总结文件。
- 每个已处理部分的文件名都包含最终内容标签。
- 每份总结都明确使用了同文章的所有先前总结作为上下文。
- `manifest.json` 可追溯拆分文件到源文件和章节范围。

## 兜底分析清单

当子技能不可用时，使用此清单继续分析：

- **角色**：人物的欲望、恐惧、能力边界、关系变化和可被读者记住的特征。
- **冲突**：表层目标冲突、价值观冲突、资源冲突、身份冲突、长期核心矛盾。
- **悬念**：读者已知、角色未知；角色已知、读者未知；双方都未知但被反复暗示。
- **背景**：规则、限制、代价、历史、地理、势力、技术/修行/制度设定。
- **大纲**：事件顺序、因果链、关键转折、高潮、后果。
- **视角**：信息差、可信度、镜头距离、叙述者是否隐瞒。
- **节奏**：动作短促、心理铺陈、描述停顿、对话推进、章节钩子。
