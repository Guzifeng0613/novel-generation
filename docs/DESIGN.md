# 编辑部工作台设计规格

本地工作台采用桌面优先的三栏编辑布局，不使用营销页、卡片瀑布或装饰性仪表盘。

## 视觉系统

- 导航底色：深墨黑 `#171a19`；次级墨色 `#232725`。
- 稿纸底色：暖白 `#f6f1e7`；正文纸面 `#fffdf8`。
- 主文字：`#252723`；次文字：`#70736b`；细边框：`#d9d2c4`。
- 批注朱红：`#a64036`；通过绿：`#39745a`；等待琥珀：`#a46a25`。
- UI 字体使用清晰的中文无衬线栈；长正文使用中文宋体/衬线栈；运行日志使用等宽字体。
- 状态同时显示图标、文字和颜色；焦点环、键盘操作和 `prefers-reduced-motion` 必须可用。

## 容器与密度

- 左栏约 248px，承载项目资产和章节树；顶部保留项目切换。
- 中央为开放稿纸，不套多层圆角卡片；工具条与内容用细线分隔。
- 右侧审稿栏约 328px，展示 Canon、悬念和问题证据。
- 底部 34px 状态条展示真实队列、token、费用和连接状态。
- 小于 1024px 时右栏变为抽屉；手机只支持监控、批准和下载。

## 核心状态

1. 项目书架与素材导入。
2. 拆分/总结运行监控。
3. 章纲待审批、退回修改和版本冻结。
4. 章节写作、五组审校、修订轮次和问题定位。
5. 正文/修订差异视图。
6. 最终交付与可恢复项目包下载。

界面不得显示虚构进度或示例费用；API 无数据时显示明确空状态。
